## [0.1.0] - 2025-03-XX

### Added
- Initial release of Limit
- Multi-provider LLM support (OpenAI, Anthropic, etc.)
- Interactive CLI with TUI support
- Session persistence and management
- Git integration (status, diff, log, commit, push, pull)
- File operations (read, write, edit)
- AST-based code search (Rust, TypeScript, Python)
- LSP integration (go-to-definition, find-references)
- Grep search functionality
- Workspace support for multi-crate Rust projects
